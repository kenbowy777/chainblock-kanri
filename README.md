# チェーンブロック 貸出・在庫・点検管理

チェーンブロックの在庫、貸し出し、および1年点検（点検ステッカー）を管理するツールです。
HTMLファイル1つで動作し、サーバーやインストールは不要です。

**利用URL**: https://kenbowy777.github.io/chainblock-kanri/

## できること

### 在庫管理
- 管理番号（八＋数字6桁）、メーカー、機種、定格荷重、保管場所、取得日を登録
- 定格荷重は 0.5t / 1t / 1.5t / 2t / 3t から選択
- メーカーはキトー・象印から選択（その他のメーカーは名称を入力）
- 機種は自由入力。過去に登録した機種名が、選択中のメーカーで絞り込まれて入力候補に出る
- 管理番号での検索（「八」を除いた数字でも検索可能）、メーカー別・定格荷重別・状態別の絞り込み

### 貸し出し管理
- 貸出先、社内担当者、貸出日、返却予定日を記録
- 貸し出し時に点検ステッカーの有効期限を自動判定
  - **未点検・点検切れ・点検中の機器は貸し出せない**（ボタンが無効になる）
  - 期限が30日以内に迫っている場合は警告を表示（貸し出しは可能）
- 機器ごとの貸出履歴を保持

### 点検管理
- 点検日を記録すると、**1年後の有効期限**を自動計算して在庫情報に反映
- 点検ステッカー番号を在庫情報とあわせて管理
- **返却を登録すると、分解点検の記録画面が自動で開く**。合格して点検ステッカーを貼付するまで在庫中に戻らない
- 点検結果は 合格 / 要修理 / 不合格 から選択。要修理・不合格の機器は貸し出せない
- 機器ごとの点検履歴を保持

### 集計
- 登録在庫数、貸出中、点検期限間近、点検切れ・未点検の件数を常時表示
- 定格荷重ごとの在庫状況（総数・貸出可能・貸出中・点検待ち・点検切れ）を一覧表示

## 使い方

1. 上記URLを開く（スマホは「ホーム画面に追加」でアプリのように起動できます）
2. 「＋ 新規在庫登録」から機器を登録
3. 「点検記録」から初回点検を登録すると、貸し出しが可能になる
4. 以降は「貸出」→「返却」→（自動で開く）「分解点検」の流れで運用

`chainblock_testdata_30.json` を画面右上の「JSONインポート」から読み込むと、
30件分のサンプルデータで動作を試せます。

## データの保存について

- データは**利用している端末のブラウザ内（localStorage）にのみ保存**されます。
  サーバーには送信されません。
- そのため、**端末が違うとデータは共有されません**。台帳を1か所で管理する場合は、
  操作する端末を1台に決めてください。
- ブラウザの履歴削除・サイトデータ消去を行うとデータも消えます。
  定期的に「JSONエクスポート」でバックアップを取ってください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 本体。これ1つで動作する |
| `manifest.json`, `icon-*.png`, `apple-touch-icon-180.png` | ホーム画面に追加するためのアイコン等 |
| `chainblock_testdata_30.json` | 動作確認用のサンプルデータ30件 |
| `chainblock_test.js` | 自動テスト（Node.js + Playwright。通常の運用では不要） |

## 自動テストの実行

```bash
npm install playwright
node chainblock_test.js
```

在庫登録から貸出・返却・分解点検までを実際の画面操作で検証します（検証項目42件）。
